RAMN ECUA CDC Serial Over USB/IP
=================================

Overview
--------
This integration exposes the CDC (Communications Device Class) serial interface
of the RAMN ECUA STM32L552 emulation over USB/IP to the host machine. This
allows the host to interact with the simulated device's serial interface as if
it were a physical USB device.

Prerequisites
-------------
- Renode with USB/IP support
- Linux: ``usbip-utils`` package (``apt install linux-tools-generic``)
- macOS/Windows: USB/IP client tools

Running
-------

1. Start the emulation::

    renode scripts/complex/ramn_ecua/ramn_cdc_serial_usbip.resc

2. On the host, enumerate USB/IP devices::

    usbip list -r 127.0.0.1

3. Attach the device::

    sudo usbip attach -r 127.0.0.1 -b 1-1

4. Access the serial port::

    # Linux
    ls /dev/ttyACM*
    minicom -D /dev/ttyACM0 -b 115200

    # Or use screen
    screen /dev/ttyACM0 115200

    # macOS
    ls /dev/tty.usbmodem*
    screen /dev/tty.usbmodem* 115200

5. To detach when done::

    sudo usbip detach -p 0

Customization
-------------
The script uses ``usart1`` by default. To use a different UART::

    host.usb CreateRAMNCDCSerial usart2 0x0483 0x5740 0 "ramnCDC"

Custom USB vendor and product IDs can also be specified as the second and
third arguments to ``CreateRAMNCDCSerial``.

Troubleshooting
---------------
Device not enumerated:
  Check Renode logs for USB initialization errors. Verify that the USB/IP
  server was created successfully with ``emulation CreateUSBIPServer``.

Device enumerates but does not open:
  On Windows, a CDC ACM driver may need to be installed. On Linux, check
  ``dmesg`` for USB errors.

Data not flowing:
  Verify UART data is being generated by checking the UART analyzer window.
  Check USB endpoint configuration and monitor Renode logs for CDC errors.
